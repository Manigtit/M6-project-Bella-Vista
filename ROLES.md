# Rollebeskrivelser

For at gøre arbejdet mere overskueligt fordelte vi roller i gruppen. Rollerne betød ikke, at man kun måtte arbejde med sit eget område, men de viste, hvem der havde mest ansvar for de forskellige dele.

| Navn      | Rolle                  | Ansvarsområde                                                                             |
| --------- | ---------------------- | ----------------------------------------------------------------------------------------- |
| Hassan    | Project Manager        | Holder overblik over projektplan, deadlines, GitHub Project board og fordeling af opgaver |
| Abdullahi | Design Lead            | Arbejder med design, layout, billeder og det visuelle udtryk på hjemmesiden               |
| Said      | Documentation/UML Lead | Arbejder med UML-diagrammer, dokumentation og README                                      |
| Mustafa   | Frontend Lead          | Arbejder med HTML/CSS, sidens struktur og det visuelle på hjemmesiden                     |

## Refleksion over rollerne

Rollefordelingen gjorde det nemmere at holde styr på, hvem der arbejdede med hvad. Samtidig fandt vi ud af, at mange opgaver hænger sammen.

For eksempel krævede UML input fra både design og frontend, fordi diagrammerne skulle passe med det, vi faktisk havde lavet på hjemmesiden.
