# Bella Vista Restaurant

## Projektbeskrivelse

Bella Vista Restaurant er en simpel hjemmeside til en italiensk restaurant. Hjemmesiden er lavet som en statisk web-løsning med flere HTML-sider og CSS-filer.

Formålet med hjemmesiden er, at kunderne nemt kan finde information om restauranten. De skal kunne se menuen, læse om restauranten, se billeder, finde kontaktoplysninger og reservere et bord.

Projektet er lavet som en del af M6: Design af IT-baserede systemer. Fokus har derfor ikke kun været på selve hjemmesiden, men også på processen omkring design, dokumentation, GitHub, roller og samarbejde.

## Produktet

Hjemmesiden består af følgende sider:

- Forside
- Menu
- Om os
- Galleri
- Reservation
- Anmeldelser
- FAQ
- Kontakt

Siden er bygget med:

- HTML
- CSS
- Bootstrap
- JavaScript
- Billeder fra assets-mappen

## Hvordan projektet er udviklet

Vi har arbejdet med en agil tilgang, hvor vi har delt projektet op i mindre opgaver. Opgaverne blev styret gennem GitHub Projects, hvor vi brugte et Kanban-board med kolonnerne To Do, In Progress, Review og Done.

Vi har også brugt Git og GitHub til versionsstyring. Det gjorde det muligt at gemme ændringer undervejs og arbejde på forskellige dele af projektet.

Gruppen har fordelt rollerne, så alle havde et område at tage ansvar for. Samtidig har vi hjulpet hinanden på tværs, når der var brug for det.

## Sådan åbnes projektet

Projektet kan åbnes ved at dobbeltklikke på `index.html`. Herefter åbnes hjemmesiden i browseren.

Man kan også åbne hele projektmappen i Visual Studio Code og arbejde videre med HTML, CSS og JavaScript derfra.
